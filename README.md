# El viaje de las 25 estrellas — libro interactivo

Libro digital basado en la presentación original de **El viaje de las 25 estrellas** de Escuela Los Lirios.

Incluye:
- Efecto de hojeo 3D.
- Sonido de página generado en el navegador al pasar de página.
- Controles anterior/siguiente.
- Navegación con teclado y gestos táctiles.
- Pantalla completa.
- Compatible con GitHub Pages.

## Publicarlo en GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube `index.html` y la carpeta `pages` completa.
3. En **Settings → Pages**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda y espera la publicación.

GitHub te entregará una URL pública con formato similar a:
`https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`

La primera interacción del visitante habilita el audio en navegadores que bloquean sonido automático.
